# Status and exact scope

## Mathematical claim

Complete joint-size classification, up to explicit logarithmic factors, for every fixed real `p > 2`, every integer `k >= 1`, every `0 < epsilon < 1/2`, arbitrary finite input matrices and ambient dimensions, and nonnegative weights on original row indices.

Part I proves the new non-even lower bound with logarithmic loss `log^(5p/2+3)(2k/epsilon)`. The non-even upper bound is imported from Lin–Mirrokni–Woodruff, Theorem 1.2. The complete even-power proof is included unchanged as Part II, not treated as an independently verified external assertion.

No intermediate-accuracy or non-even regime is deliberately omitted. The subsidiary proposed bound is refuted for each fixed exponent.
