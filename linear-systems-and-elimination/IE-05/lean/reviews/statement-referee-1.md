The left growth set existentially ranges over every actual real orthogonal
matrix and every admissible pivot path. A path gives the selected current row
at each stage, so it includes all histories generated by arbitrary tie choices.
The right path is an explicit ascending scan over `List.finRange n`, initialized
at the current first row and changed only upon a strictly larger magnitude.
Thus ties retain the smallest available current position. `FirstAvailablePivot`

The elimination definitions implement the usual row swap followed by
`B[i,j] - B[i,k] / B[k,k] * B[k,j]`, for exactly `i,j > k`. The pivot is required
to be active, nonzero, and largest in its active first column. Inactive entries
are padded with zero; eliminated multipliers are not counted in growth.
The numerator ranges over exactly stages `0,...,n-1`, includes the input and
the final scalar pivot, and excludes the post-elimination zero matrix.

maximum of absolute real entries. It is not a matrix operator norm or a norm
