## Target preservation

`BlockLanczosConjecture` contains the complete canonical largest-full-iteration
assertion, including universal `n,p,A,V,s,k,j,i`, actual real symmetry, full column
rank of `V`, every allowed iteration pair, and arbitrary independently chosen
orthonormal bases. `FullPrefixBlockLanczosClaim` contains the source proof's
slightly stronger theorem: any full-dimensional prefix endpoint `s` suffices.
The separate reduction to the canonical version is also a Challenge export.

The pairwise basis quantification exactly covers the claimed spectral property:
it only uses `Qk,Qj`; arbitrary choices at other iterations do not enter it.
Existence of every required basis is an explicit obligation, as is independence
of all ordered spectral values from that choice. No algorithmic compatibility or
block-tridiagonal recurrence is needed to state the original invariant spectral
claim. The Krylov spaces themselves remain the actual spaces generated by `A,V`.

In the canonical largest-index convention positive block width is implicit in
the existence of such an index. `lastFullBlockIteration_exists` makes the
necessary `0 < p` premise explicit. It does not assert a largest index for `p=0`.
The stronger full-prefix version includes all natural dimensions, including zero,
and its original `i` bounds handle empty cases without imposing a new nonempty
interval assumption.

The source eigenvalues are increasingly ordered with multiplicity. The formal
definition reverses the pinned self-adjoint library's decreasing order and uses
the matching reversed orthonormal eigenbasis. Equality with characteristic roots
is multiset equality, retaining every algebraic multiplicity. No simple-spectrum
or distinct-endpoint premise is introduced. The target's `i-1,i+p-1` conversion
is separately proved to be in bounds; it cannot access the total helper's
out-of-range default.

`FullBlockDimension`, `FullColumnRank`, and `IsKrylovBasis` do not contain the
spectral conclusion, a gap-contradiction hypothesis, or quadratic nonannihilation.
The only `hgap` premise occurs in the auxiliary spectral sign lemma used under
contradiction. The complete target has no such premise. The main propositions
are explicitly named target predicates, not fields in a purported input model.

The ambient representative for `q(H_ell)` is
`Qell * q(Qellᵀ A Qell) * Qellᵀ`. It is the genuine subspace operator extended by
zero. Taking the polynomial of the ambient zero-extended first compression
instead would introduce `ab(I-Pell)` on the orthogonal complement. The present
definition avoids that mismatch. The earlier **quadratic form** is compared with
the later one; only the later squared action is identified with `A²x`.
